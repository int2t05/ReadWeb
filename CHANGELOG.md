# Changelog

User-visible changes are recorded here for each release.

## 1.0.0 — 2026-10-15

- Open ordinary HTTP(S) pages in a simple multi-tab reader.
- Render online Markdown in a bundled, consistent reading view.
- Add local bookmarks, Markdown outline jumps, adjustable text size, and reading progress.
- Limit resident WebViews and saved tabs to keep resource use bounded.
- Restrict Markdown input size, encoding, redirects, raw HTML, and link schemes.
