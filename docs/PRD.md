# ReadWeb 产品需求文档（PRD）

- **版本：** 1.0.0 需求基线
- **状态：** 核心阅读流程已在 API 36 模拟器验收；目标真机与性能目标仍待验证
- **更新日期：** 2026-10-15
- **读者：** 产品维护者、实现者和测试者

本文定义首版的用户范围、产品行为与验收条件。产品决策和技术实现事实分别以本文件与 [技术设计](TECH.md) 为准；竞品依据见 [竞品可信度评估](research/competitor-review.md)。

## 1. 产品目标

ReadWeb 是一款面向 Android 的轻量阅读应用。用户可以在多个标签中打开网页，也可以把在线 Markdown 文档切换为统一阅读排版。首版优先保证操作简单、页面可恢复、资源使用可控。

### 已确认的产品决策

| 领域 | 决策 |
| --- | --- |
| 平台 | Android |
| 内容来源 | 普通网页与在线 Markdown；首版不导入本地文件 |
| 网页显示 | 保留网站原有页面和交互 |
| Markdown 显示 | 使用统一阅读排版、可调字号与标题大纲 |
| 登录 | 当前目标场景不涉及登录；登录网站不列入首版验收 |
| 标签 | 支持多个 URL，切换后继续阅读 |
| 产品边界 | 不加入社交、推送、账号同步、插件、AI、下载管理或后台保活 |

“简洁”主要指应用自身界面，不要求改写普通网站。完整离线网页归档、预加载、广告过滤、公式和 Mermaid 暂不纳入首版。

## 2. 主要使用流程

1. 用户输入或粘贴 HTTP(S) 地址，在当前或新标签中打开。
2. 普通网页按网站原样显示；在线 Markdown 文档显示为应用统一的阅读视图。
3. 用户切换标签或使用收藏夹返回页面。
4. 应用保存标签与选中项；重新启动后恢复 URL 和尽力恢复阅读位置。

## 3. 功能需求与验收

### F-01 打开网页

- 接受 HTTP 与 HTTPS 地址；未写协议时按 HTTPS 处理，拒绝在 WebView 中直接执行其他协议。
- 提供加载状态、刷新、前进和后退；无效地址应给出可理解的反馈。

### F-02 多标签

- 用户可以新增、选择和关闭标签，最多保留 10 个逻辑标签。
- 同时最多驻留 2 个 WebView。被回收的标签保留地址，切回时重新加载并尽力恢复滚动位置。
- 关闭最后一个标签后回到空白入口；达到上限时明确告知用户。

### F-03 网页导航

- 普通链接在当前标签打开；用户明确触发的新窗口可以打开新标签。
- 阻止网站自动创建弹窗。普通网页保持网站自身的布局与交互。

### F-04 在线 Markdown

- 路径以 .md 或 .markdown 结尾的 HTTP(S) 地址可进入 Markdown 阅读视图，查询参数和片段不影响识别。
- 提供“按 Markdown 阅读”操作，以支持没有文件扩展名的文本地址。
- 若响应为 HTML，显示普通网页；Markdown 获取失败时保留地址并允许重试。
- 只接受 UTF-8 Markdown 文本，最大 2 MiB；超限或不支持的内容应明确报错。
- 相对图片和链接按最终响应地址解析。

### F-05 Markdown 排版

- 支持标题、段落、强调、列表、引用、链接、图片、表格和围栏代码块。
- 图片不超出正文宽度；表格与代码块在需要时可横向滚动。
- 支持浅色/深色阅读视图和可调字号。普通网页不受 Markdown 排版设置影响。
- 不解析原始 HTML；危险链接不得执行。

### F-06 会话保存与恢复

- 标签顺序、标签地址和当前选择保存在设备本地；应用重启后恢复这些信息。
- 在标签切换和应用暂停时保存滚动位置，并在重新加载时尽力恢复。
- 不承诺恢复完整网页 DOM、表单内容或已被回收页面的前进/后退历史。

### F-07 故障处理

- 对无效地址、网络失败、Markdown 格式或大小错误、TLS 证书错误和 WebView 渲染进程退出提供明确反馈。
- TLS 错误不得忽略或绕过。
- 可刷新普通网页，或重新执行 Markdown 阅读操作。

### F-08 阅读功能区

- 左侧功能区集中呈现当前页面收藏操作、收藏夹、Markdown 字号、标题大纲和阅读进度。
- 大纲仅读取 Markdown 的 h1–h6 标题；点击标题可跳转到文档对应位置。
- 大纲最多显示前 300 个标题，每个标题最多显示 200 个字符。

### F-09 收藏夹

- 用户可以收藏当前 HTTP(S) 页面、从列表重新打开和删除收藏。
- 收藏按规范化 URL 去重，最多 100 条；标题最多 200 个字符，网址最多 2048 个字符。
- 收藏仅保存在本机，不提供同步或导出。

### F-10 字号与进度

- Markdown 字号范围为 14–28 px，设置跨标签和应用重启保留；字号设置只应用于 Markdown 阅读视图。
- 阅读进度显示当前页面滚动位置相对于可滚动高度的估算百分比；不生成额外阅读历史。
- 短于一屏的页面显示为已读。

## 4. 质量要求与验证目标

以下是**建议用于首轮设备验证的目标值**，不是已经测得或已确认的性能承诺。设备型号、Android/OriginOS 版本和常读 URL 尚未提供；验证结果必须记录设备、WebView 版本、网络条件和样本页面。

| 项目 | 建议验证条件 |
| --- | --- |
| 冷启动 | 10 次发布构建启动，中位数不超过 2 秒；从启动到地址栏可操作，不计网页网络加载 |
| 驻留标签切换 | 已驻留页面切换后 300 ms 内可操作 |
| Markdown 首屏 | 200 KiB 固定样本，从文本获取完成至可阅读的中位数不超过 1 秒 |
| 内存 | 在 1、6、10 个逻辑标签下记录宿主和渲染进程 PSS；循环新建/关闭 50 次后复测。绝对内存预算待基线确定 |
| 稳定性 | 固定样本连续阅读、切换 30 分钟，无崩溃、ANR 或无法恢复的白屏 |
| 恢复 | 验证旋转、后台切回、进程重建后的标签顺序、地址、选中项和滚动位置 |
| 异常与安全 | 验证断网、超时、HTTP 错误、TLS 错误、超大 Markdown 和危险链接的反馈与拒绝行为 |

建议样本覆盖长文章、动态网页、原始 Markdown、带查询参数与重定向的 Markdown、相对图片、中文、宽表格、长代码块及恶意 HTML。用户提供常读 URL 后，应补充到测试集。桌面自动化检查不替代设备上的性能和交互验证。

## 5. 首版交付状态

版本号已提升为 `1.0.0`。自动化单测、Markdown renderer 测试、依赖审计、Android lint、Debug 安装及 API 36 模拟器核心交互检查已完成。Vivo/OriginOS 真机兼容性、长时间稳定性和第 4 节性能指标尚未验证；这些结果不会由桌面构建代替。验证细节与环境记录见 [技术设计](TECH.md)。
