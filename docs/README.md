# Documentation

This folder contains the product contract and engineering record for ReadWeb.

- [Product requirements](PRD.md) — confirmed product scope, first-release behavior, acceptance criteria, and decisions still open for review.
- [Technical design](TECH.md) — implementation choices, security boundaries, build configuration, verification evidence, and runtime checks that remain outstanding.
- [Release procedure](RELEASING.md) — signing requirements, tag-based publication, and recovery steps.
- [Release notes](releases/1.0.0.md) — scope of the first release.
- [Pre-release readiness snapshot](audit/2026-10-15-release-readiness.md) — emulator evidence, fixes, and publication gates recorded before remote setup.
- [Publication verification](audit/2026-10-15-publication.md) — public release, workflow results, signed APK, checksum, and emulator evidence.
- [Competitor and approach review](research/competitor-review.md) — source-backed assessment of the original competitor and WebView claims.

Use PRD.md as the source for what the app should do. Use TECH.md as the source for how the current implementation works. Performance figures in the PRD are candidate device-test targets, not measured results.
