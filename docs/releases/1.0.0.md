# ReadWeb 1.0.0

First stable release of the focused Android web and Markdown reader.

- Read ordinary HTTP(S) websites in their original layout.
- Render online Markdown with a bundled markdown-it reader.
- Use multiple tabs with a two-WebView resident limit.
- Save local bookmarks and restore tab URLs after a restart.
- Adjust Markdown font size, jump from the heading outline, and track estimated page progress.

Markdown is online-only. Local-file import, offline archives, site login guarantees, and device-specific performance guarantees are outside this release.
